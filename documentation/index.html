A) Server Requirements - top

Before installing Lumora AI, ensure your server meets the following minimum requirements:

  • Node.js - Version 18.0 or higher (recommended: v20 LTS)
  • MySQL - Version 5.7 or higher (recommended: v8.0)
  • npm - Version 9.0 or higher
  • RAM - Minimum 512MB (recommended: 1GB+)
  • Storage - Minimum 500MB free space
  • SSL Certificate - Required for production (HTTPS)
  • PM2 - Process manager for Node.js (for production)

Supported Hosting:

  • VPS (DigitalOcean, Vultr, Linode, AWS EC2)
  • aaPanel / BT Panel hosting
  • cPanel with Node.js support
  • Vercel (easiest deployment)
  • Any Linux server with Node.js

B) Installation Guide - top

Follow these steps to install Lumora AI on your server:

Step 1: Upload Files

Upload all project files to your web server directory. For example:

	/www/wwwroot/yourdomain.com/
	   or
	/var/www/yourdomain.com/

Step 2: Install Dependencies

	cd /path/to/your/project
	npm install

Step 3: Configure Environment

	cp .env.example .env.local
	nano .env.local

Fill in your database credentials, API keys, and secrets. See section D for full details.

Step 4: Generate Security Keys

	openssl rand -hex 32    # Use for JWT_SECRET
	openssl rand -hex 16    # Use for CSRF_SECRET
	openssl rand -hex 16    # Use for ENCRYPTION_KEY

Step 5: Setup Database

	mysql -u YOUR_USER -p YOUR_DATABASE < src/lib/database/schema.sql

Step 6: Build the Project

	npm run build

Step 7: Start the Application

	# Install PM2 (production process manager)
	npm install -g pm2

	# Start on your chosen port (avoid common ports like 3000/4000)
	pm2 start npm --name "lumora-ai" -- start -- -p 7847

	# Enable auto-restart on server reboot
	pm2 startup
	pm2 save

Step 8: Configure Reverse Proxy (Nginx)

Add this to your Nginx site configuration:

	location / {
	    proxy_pass http://127.0.0.1:7847;
	    proxy_http_version 1.1;
	    proxy_set_header Upgrade $http_upgrade;
	    proxy_set_header Connection 'upgrade';
	    proxy_set_header Host $host;
	    proxy_set_header X-Real-IP $remote_addr;
	    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
	    proxy_set_header X-Forwarded-Proto $scheme;
	    proxy_cache_bypass $http_upgrade;
	    proxy_read_timeout 86400s;
	    proxy_send_timeout 86400s;
	}

Step 9: Access Installer

Visit https://yourdomain.com/install to complete setup via the web installer.

Step 10: Finalize

After the installer completes, set INSTALLED=true in your .env.local file and restart:

	pm2 restart lumora-ai

C) Database Setup - top

Lumora AI uses MySQL as its database. Here's how to set it up:

Create Database:

	mysql -u root -p
	CREATE DATABASE lumora_ai CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
	CREATE USER 'lumora_user'@'localhost' IDENTIFIED BY 'your_secure_password';
	GRANT ALL PRIVILEGES ON lumora_ai.* TO 'lumora_user'@'localhost';
	FLUSH PRIVILEGES;
	EXIT;

Import Schema:

	mysql -u lumora_user -p lumora_ai < src/lib/database/schema.sql

Database Tables Created:

  • users - User accounts and profiles
  • user_sessions - Active login sessions
  • conversations - Chat conversations
  • messages - Individual chat messages
  • subscription_plans - Available plans (Free, Pro, Enterprise)
  • user_subscriptions - User plan assignments
  • payments - Payment transaction history
  • ai_providers - AI provider configurations
  • usage_logs - API usage tracking
  • coupons - Discount coupon codes
  • support_tickets - User support requests
  • announcements - System announcements
  • site_settings - Platform configuration
  • blog_posts - Blog content
  • image_generations - AI image history
  • notifications - User notifications
  • license_activations - License tracking
  • system_logs - Error and system logs

The schema also inserts default subscription plans (Free, Pro, Enterprise) and default AI providers (Gemini, OpenAI, Claude, Grok).

D) Environment Configuration - top

All configuration is managed through the .env.local file. Here is a complete reference:

Application Settings:

	NEXT_PUBLIC_APP_NAME="Lumora AI"
	NEXT_PUBLIC_APP_URL=https://yourdomain.com
	NEXT_PUBLIC_APP_VERSION=1.0.0
	APP_ENVIRONMENT=production
	INSTALLED=true

Database:

	DB_HOST=localhost
	DB_PORT=3306
	DB_NAME=lumora_ai
	DB_USER=your_db_user
	DB_PASSWORD=your_db_password

Authentication:

	JWT_SECRET=your-64-char-random-hex-string
	JWT_EXPIRY=7d
	REFRESH_TOKEN_EXPIRY=30d
	SESSION_COOKIE_NAME=lumora_session

Security:

	CSRF_SECRET=your-32-char-random-hex-string
	ENCRYPTION_KEY=your-32-char-random-hex-string

Rate Limiting:

	RATE_LIMIT_WINDOW=900000
	RATE_LIMIT_MAX_REQUESTS=100
	AUTH_RATE_LIMIT_MAX=5

Important: Never commit .env.local to version control. It contains sensitive secrets.

E) AI Provider Setup - top

Lumora AI supports 4 AI providers. You need at least one API key (Gemini recommended for free tier).

1. Google Gemini (Recommended - has free tier)

  1. Go to https://aistudio.google.com/apikey
  2. Click "Create API Key"
  3. Copy the key and add to .env.local:
	GEMINI_API_KEY=your-gemini-api-key

2. OpenAI (GPT-4)

  1. Go to https://platform.openai.com/api-keys
  2. Create a new secret key
  3. Add billing/credits to your account
  4. Add to .env.local:
	OPENAI_API_KEY=sk-your-openai-key

3. Anthropic Claude

  1. Go to https://console.anthropic.com/
  2. Create an API key
  3. Add to .env.local:
	CLAUDE_API_KEY=sk-ant-your-claude-key

4. xAI Grok

  1. Go to https://console.x.ai/
  2. Generate an API key
  3. Add to .env.local:
	GROK_API_KEY=your-grok-api-key

Admin Management: After setup, you can enable/disable providers and manage API keys from the Admin Panel > AI Providers page.

F) Payment Gateway Configuration - top

Lumora AI supports multiple payment gateways. Configure only the ones you need:

Stripe (Recommended)

  1. Create account at stripe.com
  2. Go to Developers > API Keys
  3. Copy Publishable key and Secret key
  4. Set up a webhook endpoint: https://yourdomain.com/api/payments/webhook/stripe
	STRIPE_PUBLIC_KEY=pk_live_your-key
	STRIPE_SECRET_KEY=sk_live_your-key
	STRIPE_WEBHOOK_SECRET=whsec_your-webhook-secret

PayPal

  1. Go to developer.paypal.com
  2. Create an app and get Client ID and Secret
	PAYPAL_CLIENT_ID=your-client-id
	PAYPAL_CLIENT_SECRET=your-client-secret
	PAYPAL_MODE=live

Razorpay (India)

	RAZORPAY_KEY_ID=rzp_live_your-key
	RAZORPAY_KEY_SECRET=your-secret

PayHere (Sri Lanka)

	PAYHERE_MERCHANT_ID=your-merchant-id
	PAYHERE_MERCHANT_SECRET=your-merchant-secret
	PAYHERE_MODE=live

Paddle

	PADDLE_VENDOR_ID=your-vendor-id
	PADDLE_API_KEY=your-api-key

LemonSqueezy

	LEMONSQUEEZY_API_KEY=your-api-key
	LEMONSQUEEZY_STORE_ID=your-store-id

Note: You only need to configure one gateway to get started. Stripe is recommended for most users.

G) SMTP / Email Setup - top

Email is used for user verification, password resets, and notifications. Configure your SMTP provider:

Gmail Example:

	SMTP_HOST=smtp.gmail.com
	SMTP_PORT=587
	SMTP_USER=your-email@gmail.com
	SMTP_PASSWORD=your-app-password
	SMTP_FROM_NAME="Lumora AI"
	SMTP_FROM_EMAIL=noreply@yourdomain.com

Important for Gmail: You need to use an "App Password" not your regular password. Go to Google Account > Security > 2-Step Verification > App Passwords.

Other SMTP Providers:

  • SendGrid: Host: smtp.sendgrid.net, Port: 587
  • Mailgun: Host: smtp.mailgun.org, Port: 587
  • Amazon SES: Host: email-smtp.us-east-1.amazonaws.com, Port: 587
  • Zoho: Host: smtp.zoho.com, Port: 465

You can test your email configuration from Admin Panel > Settings > Email > "Send Test Email".

H) Deployment Options - top

Lumora AI can be deployed on various platforms:

Option 1: VPS with aaPanel/BT Panel

  1. Upload files to /www/wwwroot/yourdomain.com/
  2. Run npm install && npm run build
  3. Start with PM2: pm2 start npm --name "lumora-ai" -- start -- -p 7847
  4. Add reverse proxy in your panel pointing to http://127.0.0.1:7847
  5. Enable SSL certificate

Option 2: Vercel (Easiest)

  1. Push code to GitHub
  2. Connect repository to vercel.com
  3. Add environment variables in Vercel dashboard
  4. Deploy automatically

Note: You'll need an external MySQL database (PlanetScale, AWS RDS, etc.)

Option 3: cPanel with Node.js

  1. Upload files via File Manager or SSH
  2. Go to Setup Node.js App in cPanel
  3. Create application, set entry point to node_modules/.bin/next start -p PORT
  4. Set environment variables
  5. Run npm install and build commands

Option 4: Docker

	docker build -t lumora-ai .
	docker run -p 7847:7847 --env-file .env.local lumora-ai

PM2 Useful Commands:

	pm2 start lumora-ai      # Start
	pm2 stop lumora-ai       # Stop
	pm2 restart lumora-ai    # Restart
	pm2 logs lumora-ai       # View logs
	pm2 monit                # Monitor CPU/Memory
	pm2 delete lumora-ai     # Remove process

K) License Verification - top

Lumora AI includes an Envato purchase code verification system.

How it works:

  1. During installation, user enters their Envato purchase code
  2. The system verifies the code via Envato API
  3. On success, the activation is stored in the database
  4. License status can be viewed in Admin Panel > License

For developers (configuring verification):

Add your Envato personal token to .env.local:

	ENVATO_PERSONAL_TOKEN=your-envato-personal-token
	ENVATO_ITEM_ID=your-item-id-from-codecanyon

To get your personal token:

  1. Go to https://build.envato.com/create-token/
  2. Enable "View Your Envato Account Username"
  3. Enable "View the user's purchases of the app creator's items"
  4. Create token and copy it

Development Mode: Set APP_ENVIRONMENT=development to bypass license verification during development.

M) Customization Guide - top

Changing Brand Colors:

Edit src/app/globals.css and modify the CSS variables:

	:root {
	    --brand-primary: #6366f1;       /* Change to your color */
	    --brand-secondary: #8b5cf6;     /* Change to your color */
	    --brand-gradient: linear-gradient(135deg, #6366f1 0%, #8b5cf6 50%, #a78bfa 100%);
	}

Changing Site Name & Branding:

  1. Update NEXT_PUBLIC_APP_NAME in .env.local
  2. Replace logo in public/images/logo.svg
  3. Update metadata in src/app/layout.jsx
  4. Update Admin Panel > Settings > General

Modifying Landing Page:

Edit src/app/page.jsx to change:

  • Hero text and description
  • Feature list (at bottom of file)
  • Pricing plans data
  • Testimonials

Adding New AI Providers:

  1. Create a new file in src/lib/ai-providers/your-provider.js
  2. Implement the callYourProvider({ model, messages, onChunk }) function
  3. Register it in src/lib/ai-providers/router.js
  4. Add models to src/components/chat/ChatInput.jsx

Adding New Payment Gateways:

  1. Create integration file in src/lib/payments/your-gateway.js
  2. Register in src/lib/payments/gateway-router.js
  3. Add env variables to .env.example

N) Troubleshooting - top

Issue: Site shows blank page or 502 error

  • Check if PM2 process is running: pm2 status
  • Check logs: pm2 logs lumora-ai
  • Ensure Nginx reverse proxy points to correct port
  • Verify the app built successfully: npm run build

Issue: Database connection error

  • Verify credentials in .env.local
  • Ensure MySQL is running: systemctl status mysql
  • Test connection: mysql -u your_user -p your_database
  • Check if database exists and schema is imported

Issue: AI chat not responding

  • Verify AI API key is set in .env.local
  • Check provider is enabled in Admin Panel > AI Providers
  • Test API key directly with curl
  • Check logs for API errors: pm2 logs lumora-ai

Issue: Text invisible on landing page

  • Clear browser cache (Ctrl+Shift+R)
  • Try incognito/private window
  • Rebuild: rm -rf .next && npm run build
  • Restart: pm2 restart lumora-ai

Issue: Email not sending

  • Verify SMTP credentials in .env.local
  • For Gmail: use App Password, not regular password
  • Check port (587 for TLS, 465 for SSL)
  • Test from Admin Panel > Settings > Email

Issue: Payment not processing

  • Ensure payment gateway keys are for live mode (not test/sandbox)
  • Verify webhook URL is accessible publicly
  • Check Stripe/PayPal dashboard for error logs

Common Commands:

	pm2 logs lumora-ai --lines 50    # View recent logs
	pm2 restart lumora-ai            # Restart after changes
	rm -rf .next && npm run build    # Full rebuild
	nginx -t && nginx -s reload      # Test & reload Nginx
