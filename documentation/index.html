A) What is Lumora AI? - top

Lumora AI is a complete, ready-to-use AI chat platform — similar to ChatGPT — that you can install on your own server and run as a business. Your users can sign up, chat with AI, and pay for premium features through subscriptions.

What’s included:

  • AI Chat — Users can chat with Google Gemini, OpenAI GPT-4, Claude, and Grok
  • User Accounts — Registration, login, password reset, email verification
  • Subscription System — Free, Pro, and Enterprise plans with payment processing
  • Admin Dashboard — Manage everything from a beautiful control panel
  • Landing Page — Professional marketing page to attract customers
  • Installation Wizard — Easy setup process that guides you through configuration

How it works (simple explanation):

  1. You upload the files to your web server (like uploading files to a website)
  2. You run a few commands to set it up
  3. Users visit your website, create accounts, and start chatting with AI
  4. You earn money through subscriptions

C) Step-by-Step Installation - top

Follow these steps exactly in order. Each step must be completed before moving to the next.

Step 1: Connect to your server

Open a terminal (Mac/Linux) or PuTTY (Windows) and connect to your server using SSH:

	ssh root@your-server-ip-address

Replace "your-server-ip-address" with the actual IP from your hosting provider (e.g., 123.45.67.89)

Step 2: Navigate to your website folder

Go to the directory where your website files should be stored:

	cd /www/wwwroot/yourdomain.com

Replace "yourdomain.com" with your actual domain name

Step 3: Upload the project files

You can either clone from git or upload via FTP/SFTP. The easiest way:

	# Remove any existing files in the folder
	rm -rf *

	# Upload your purchased files here via FTP
	# OR clone from your repository

Step 4: Install the required packages

This downloads all the code libraries that Lumora AI needs to work:

	npm install

This will take 1-3 minutes. Wait until it finishes (you’ll see your cursor return to normal).

Step 5: Create your settings file

Copy the example settings file and open it for editing:

	cp .env.example .env.local
	nano .env.local

"nano" is a text editor. After making changes, press Ctrl+X, then Y, then Enter to save.

What is .env.local? This file contains all your passwords, API keys, and settings. Think of it as the “control panel” for your entire application. We’ll fill it in during the next sections.

Step 6: Generate security keys

Run these 3 commands one by one. Each will print a random string of characters. Copy each one and paste into your .env.local file in the correct place:

	openssl rand -hex 32

Copy the output → paste as your JWT_SECRET value in .env.local

	openssl rand -hex 16

Copy the output → paste as your CSRF_SECRET value in .env.local

	openssl rand -hex 16

Copy the output → paste as your ENCRYPTION_KEY value in .env.local

Never share these keys! They protect your users’ passwords and sessions. If someone gets these keys, they could access your users’ accounts.

Step 7: Build the application

This compiles all the code into an optimized version ready for production:

	npm run build

This takes 1-5 minutes depending on your server speed. Wait for it to complete without errors.

D) Setting Up Your Database - top

What is a database? A database is where all user accounts, conversations, payments, and settings are stored. Think of it like a filing cabinet for your application.

Step 1: Create a new database

If you’re using aaPanel or BT Panel, go to Databases → Add Database. Note down:

  • Database name (e.g., lumora_ai)
  • Database username (e.g., lumora_user)
  • Database password (the panel will generate one)

If you prefer using the command line:

	mysql -u root -p
	CREATE DATABASE lumora_ai CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
	EXIT;

Step 2: Import the table structure

This creates all the required tables (users, conversations, etc.):

	mysql -u YOUR_DB_USER -p YOUR_DB_NAME < src/lib/database/schema.sql

Replace YOUR_DB_USER and YOUR_DB_NAME with your actual database credentials.

It will ask for your database password. Type it and press Enter (you won’t see the characters as you type — that’s normal).

Step 3: Update your .env.local file

Open .env.local and update the database section:

	DB_HOST=localhost
	DB_PORT=3306
	DB_NAME=lumora_ai
	DB_USER=your_database_username
	DB_PASSWORD=your_database_password
How do I know it worked? If the import command ran without showing any error messages, it worked! You can verify by logging into phpMyAdmin (if available) and checking that you see tables like "users", "conversations", etc.

E) Configuring Your Settings - top

Open your .env.local file (nano .env.local) and fill in each section. Here’s what each setting means:

Application Settings (tells the app about itself):

	NEXT_PUBLIC_APP_NAME="Lumora AI"          # Your site name (shown in browser tab)
	NEXT_PUBLIC_APP_URL=https://yourdomain.com # Your full website URL with https://
	APP_ENVIRONMENT=production                 # Always "production" for live sites
	INSTALLED=false                            # Change to "true" AFTER installation wizard completes

Security Settings (protects your users):

	JWT_SECRET=paste-your-generated-64-char-key-here    # From Step 6 above
	CSRF_SECRET=paste-your-generated-32-char-key-here   # From Step 6 above
	ENCRYPTION_KEY=paste-your-generated-32-char-key-here # From Step 6 above
Remember: After editing .env.local, press Ctrl+X, then Y, then Enter to save and exit the nano editor.

F) Connecting AI Providers (API Keys) - top

What is an API key? An API key is like a password that allows your website to communicate with AI services (Google, OpenAI, etc.). Without at least one key, the chat feature won’t work.

You only need ONE provider to get started. We recommend Google Gemini because it has a generous free tier.

Option 1: Google Gemini (FREE — Recommended for beginners)

  1. Go to https://aistudio.google.com/apikey
  2. Sign in with your Google account
  3. Click the blue “Create API Key” button
  4. Copy the key that appears
  5. Open your .env.local file and paste it:
	GEMINI_API_KEY=AIzaSy...your-key-here

Option 2: OpenAI / GPT-4 (Paid — starts at $5)

  1. Go to https://platform.openai.com/api-keys
  2. Create an account and add billing credits ($5 minimum)
  3. Click “Create new secret key”
  4. Copy the key and add to .env.local:
	OPENAI_API_KEY=sk-...your-key-here

Option 3: Anthropic Claude (Paid)

  1. Go to https://console.anthropic.com/
  2. Create account, add credits, create API key
  3. Add to .env.local:
	CLAUDE_API_KEY=sk-ant-...your-key-here

Option 4: xAI Grok (Paid)

  1. Go to https://console.x.ai/
  2. Create account and generate API key
  3. Add to .env.local:
	GROK_API_KEY=your-key-here
Quick start: Just set up Google Gemini for now. You can always add more providers later from the Admin Panel without touching any code.

G) Setting Up Payment Gateways - top

What is a payment gateway? It’s the service that processes credit card payments from your customers. When someone upgrades to a paid plan, the payment gateway handles the money transfer.

You can skip this step initially and just offer the free plan. Add payments later when you’re ready.

Stripe (Recommended — works worldwide):

  1. Create a free account at stripe.com
  2. Go to Developers → API Keys (in the left sidebar)
  3. Copy your “Publishable key” and “Secret key”
  4. Add to .env.local:
	STRIPE_PUBLIC_KEY=pk_live_...your-key
	STRIPE_SECRET_KEY=sk_live_...your-key
	STRIPE_WEBHOOK_SECRET=whsec_...your-webhook-key

Other supported gateways (add their keys to .env.local when needed):

  • PayPal — developer.paypal.com
  • Razorpay (India) — razorpay.com
  • PayHere (Sri Lanka) — payhere.lk
  • Paddle — paddle.com
  • LemonSqueezy — lemonsqueezy.com

H) Setting Up Email Notifications - top

What is SMTP? SMTP is the system that sends emails from your application (like “Verify your email” or “Reset your password” messages to users).

You can skip this step initially. The app will work without email, but users won’t receive verification or password reset emails.

Easiest setup — Using Gmail:

  1. Go to your Google Account → Security → 2-Step Verification (turn it ON)
  2. Then go to “App Passwords” (search for it in Google Account settings)
  3. Create a new app password for “Mail”
  4. Google will show you a 16-character password. Copy it.
  5. Add to .env.local:
	SMTP_HOST=smtp.gmail.com
	SMTP_PORT=587
	SMTP_USER=your-gmail@gmail.com
	SMTP_PASSWORD=xxxx-xxxx-xxxx-xxxx
	SMTP_FROM_NAME="Lumora AI"
	SMTP_FROM_EMAIL=your-gmail@gmail.com
Important: Use the App Password from step 4, NOT your regular Gmail password. Regular passwords won’t work.

I) Going Live (Starting Your Site) - top

Now that everything is configured, let’s start the application!

Step 1: Install the process manager

PM2 keeps your app running 24/7 (even after you close your terminal):

	npm install -g pm2

Step 2: Start the application

	pm2 start npm --name "lumora-ai" -- start -- -p 7847

This starts your site on port 7847. You’ll see a green “online” status if successful.

Step 3: Make it auto-start when server reboots

	pm2 startup
	pm2 save

Step 4: Set up the web proxy (Nginx)

You need to tell your web server to forward visitors to port 7847. In your server panel (aaPanel/BT Panel), go to your website settings and add a “Reverse Proxy” pointing to:

	http://127.0.0.1:7847

If editing Nginx config manually, add this inside your server block:

	location / {
	    proxy_pass http://127.0.0.1:7847;
	    proxy_http_version 1.1;
	    proxy_set_header Upgrade $http_upgrade;
	    proxy_set_header Connection 'upgrade';
	    proxy_set_header Host $host;
	    proxy_set_header X-Real-IP $remote_addr;
	    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
	    proxy_set_header X-Forwarded-Proto $scheme;
	    proxy_cache_bypass $http_upgrade;
	}

Step 5: Visit your site!

Open your browser and go to https://yourdomain.com — you should see the Lumora AI landing page!

Step 6: Complete the installation wizard

The first time you visit, you’ll be redirected to the installation wizard at /install. Follow the on-screen steps to verify your license, test database, and create your admin account.

Step 7: Finalize

After the wizard completes, edit your .env.local and change:

	INSTALLED=true

Then restart the app:

	pm2 restart lumora-ai
Congratulations! Your AI chat platform is now live! Visit /admin/dashboard to access the admin panel.

K) Customizing Your Platform - top

Changing your brand name:

  1. Open .env.local and change NEXT_PUBLIC_APP_NAME
  2. Go to Admin Panel → Settings → General and update the site name
  3. Rebuild: npm run build then pm2 restart lumora-ai

Changing colors:

Edit the file src/app/globals.css and find this section at the top:

	:root {
	    --brand-primary: #6366f1;    /* Main purple color */
	    --brand-secondary: #8b5cf6;  /* Secondary purple */
	}

Change the hex color codes to your preferred colors. Use colorhunt.co to find nice color combinations.

Changing subscription prices:

  1. Go to Admin Panel → Subscriptions
  2. Click “Edit” on any plan
  3. Change the monthly/yearly price
  4. Save

Editing the landing page text:

Open src/app/page.jsx in a text editor. Scroll to the bottom to find the text content (features list, pricing, testimonials). Change the text and rebuild.

After any file changes: Always run npm run build and then pm2 restart lumora-ai to apply changes.

L) Common Problems & Solutions - top

Problem: I see a blank page or 502 error

  • Check if the app is running: type pm2 status — look for “online” status
  • Check error logs: pm2 logs lumora-ai --lines 20
  • Make sure Nginx reverse proxy is set to the correct port (7847)
  • Try rebuilding: rm -rf .next && npm run build && pm2 restart lumora-ai

Problem: AI chat gives an error or doesn’t respond

  • Make sure you have at least one API key set in .env.local (GEMINI_API_KEY at minimum)
  • Verify the key works by checking the AI provider’s dashboard
  • Check logs for specific error: pm2 logs lumora-ai

Problem: Can’t log in to admin panel

  • Make sure you completed the installation wizard
  • Check that the database is connected (database credentials in .env.local are correct)
  • Try the email and password you set during installation

Problem: Site text is invisible or colors look wrong

  • Open your site in a private/incognito browser window (Ctrl+Shift+N in Chrome)
  • This clears any cached CSS files that might be outdated

Problem: Emails not being sent

  • For Gmail: make sure you’re using an App Password (not your regular password)
  • Check that 2-Step Verification is enabled on your Google account first
  • Verify SMTP settings in .env.local match exactly what’s shown in this guide

Useful commands for debugging:

	pm2 status                    # Check if app is running
	pm2 logs lumora-ai            # View error messages
	pm2 restart lumora-ai         # Restart after changes
	rm -rf .next && npm run build # Full rebuild from scratch
